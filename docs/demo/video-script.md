# Argonauts 시연 영상 대본

- 목표 길이: 약 2분 10초 (말하는 속도 기준 분당 약 300음절)
- 말투: 원고를 읽지 말고 심사위원 앞에서 직접 시연하듯이. `/`는 짧게 쉬기, **굵은 글씨**는 살짝 힘주기.
- 녹음: 장면마다 파일 하나씩 (`A01_오프닝.m4a` …). 틀리면 그 장면만 다시 녹음. 장면 사이 쉼은 편집에서 맞춘다.
- 화면: 에뮬레이터 `emulator-5558` 녹화 + 친구 휴대폰 웹은 데스크톱 Chrome 휴대폰 폭으로 녹화해 옆에 배치.

## 녹화 메모

- 터치 위치 표시: `adb -s emulator-5558 shell settings put system show_touches 1`
- 주행 화면은 adb 설치 앱이 에뮬레이터에서 차단되므로 "주행 화면 미리보기"로 보여준다 (A07).
- 휴대폰이 없으면 A05는 스크립트 ② 민수 목적지 변경 요청으로 대신하고 대사의 "조수석 친구가 휴대폰으로"는 유지한다(요청 경로만 다름).
- 엔딩 카드에 지도 출처 "© OpenStreetMap contributors" 표기.
